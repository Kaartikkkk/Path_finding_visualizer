How it Works

Step 1: Understand the Grid

The grid represents a map. The Green Node (▶) is where the search begins, and the Red Node (⬤) is the target. Empty cells are standard paths.

Step 2: Choose an Algorithm

Select an algorithm from the sidebar.
• A* Search: Smart and fast. Uses distance guessing (heuristic).
• Dijkstra's: Explores uniformly in all directions. Respects weights.
• BFS: Explores level-by-level. Good for unweighted grids.
• DFS: Blindly goes deep into one path before turning around.

Step 3: Draw Your Environment

Use the Draw Mode to place obstacles.
• Walls (🧱): Impenetrable blocks. Algorithms must path around them.
• Weights (⚖): Difficult terrain (costs 3x more to cross). Only A* and Dijkstra consider weights.
• Drag Nodes: Click and drag the Start or End nodes to move them.

Step 4: Visualize!

Click ▶ Visualize. First, you'll see the Exploration Phase (Blue) where the algorithm searches the grid. Once found, it highlights the Shortest Path (Yellow).
